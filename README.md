# spatial_snrnaseq_comparedegs

Order of operations



Get all individual sample h5ad files of xenium spatial data into one folder.

Run mergespatial.R

This ouputs one RDS object for the spatial data.

Calculate spatial DEGs using the appropriate script:
  
  spatial_pseudoDEG_hom.R for Wt v Het or Wt v Hom comparisons (specify in script user settings)
  
  spatial_pseudoDEG_X.R for Wt v combined Hom/Hemi analysis
  
  *There is also a spatial_pseudoDEG.R file which is historical code

This outputs the pseudobulked DEGs from the spatial data.


To compare DEGs use the comparespatial_snrnaseqDEGs.R file.

As input you will need the DE_all_celltypes_all_contrasts.csv for your gene of interest.

Also as input you will need the celltype DEGs output files from the snRNAseq data generated by Emma Jones (in Box).

The script will compare the DEGs in the two datasets and outputs comparison plots and a csv. 


To include an overview of comparison DEGs for multiple lines, use compfigs.R and identify the location of the results from above in the user settings.

Plots will be output and they are explained in the code.
